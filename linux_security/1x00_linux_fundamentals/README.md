# 1x00 Linux Fundamentals

## Goal

Automate file transfer and remote execution with `scp` and `ssh`, then verify the execution context by printing the effective username.

## Steps

1. Create the script locally.
2. Make it executable.
3. Test it locally.
4. Transfer it to the target machine with `scp`.
5. Execute it remotely with `ssh`.
6. Read the flag on the remote machine.
7. Download `0-flag.txt` back to your local machine with `scp`.
